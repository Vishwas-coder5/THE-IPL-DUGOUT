# 🏏 The IPL Dugout

📌 Project Overview

Bridging the thrill of IPL cricket with the science of data, this analytics project is powered by Excel , SQL and Power BI, featuring structured players data, performance metrics, batting and bowling performance strategies, matchup dynamics, and interactive visual storytelling.

**Built with a passion for cricket and data analytics.**

🎯 Project Objectives

- Explore IPL player performances and career statistics.

- Examine batting and bowling metrics to understand player contributions.

- Investigate player-versus-bowler matchups and batting-phase performance.

- Develop interactive dashboards to communicate cricket statistics effectively.

🛠️ Tools & Technologies

- Microsoft Excel — Data cleaning, data filtering, missing-value handling, and preliminary data validation.

- PostgreSQL — SQL queries, data validation, subqueries, and cross-checking data consistency.

- Microsoft Power BI — Data modeling, DAX measures, interactive dashboards, and data visualization.

- GitHub — Project documentation, repository management, and version control.

📊 Dashboard Modules

- IPL Overview — A high-level view of IPL player data and key statistics.

- IPL Master Data — Players profiles, career stats, and players attributes.

- Batting Analysis — Batting performance metrics and players season wise stats comparisons.

- Bowling Analysis — Bowling statistics and performance evaluation.

- Batsmen vs Bowlers & Batting Phases — Matchup analysis and performance across different phases of an innings.

🔍 Key Analytical Areas

- Player career and season statistics.

- Batting and bowling performance comparisons.

- Head-to-head players matchups.

- Performance across batting phases.

- Interactive exploration using slicers, filters.

🚀 Project Highlights

- Combined Excel,SQL-based data preparation with interactive Power BI reporting.

- Organized player information and performance metrics for focused analysis.

- Designed multiple dashboard pages for different analytical perspectives.

- Used data modeling and visual storytelling to make cricket statistics easier to explore.
